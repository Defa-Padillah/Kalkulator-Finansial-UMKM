📊 Kalkulator Finansial & Margin Keuntungan UMKM

Aplikasi web interaktif yang dirancang untuk membantu pemilik usaha/UMKM menentukan **Harga Jual Ideal** agar tidak rugi terpotong biaya admin marketplace/Online Shop atau *payment gateway* (Midtrans), serta menghitung **Keuntungan Bersih (Nett Profit)** secara akurat.

---

✨ Fitur Utama

🏦 **Preset Fee Platform & Payment Gateway**: Pilihan otomatis persentase fee untuk Shopee, TikTok Shop, serta Midtrans (QRIS & Virtual Account).
💡 **Rekomendasi Harga Jual Bebas Potongan**: Menggunakan rumus perhitungan khusus agar target margin bersih yang diinginkan penjual tidak tergerus biaya admin.
🧪 **Simulator Tes Harga Manual**: Fitur uji coba untuk mengecek secara otomatis apakah harga jual buatan pengguna menghasilkan profit atau justru rugi.
📱 **Tampilan Modern & Responsif**: Menggunakan antarmuka *Glassmorphism* yang nyaman diakses dari smartphone maupun PC.


🛠️ Tech Stack

- **HTML5** - Struktur antarmuka
- **CSS3** - Custom styling dengan CSS Grid & Flexbox
- **JavaScript (Vanilla JS)** - Logika perhitungan & interaktivitas DOM
